California Housing Analysis

A beginner-friendly Python data analysis project using the California Housing dataset.

About the Project

In this project, we explore the California Housing dataset and use Python to examine the data and better understand the relationship between different housing features and house values.

Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

Dataset

The project uses the California Housing dataset provided by Scikit-learn.

What I Learned

* Loading and working with datasets in Python
* Using Pandas for data analysis
* Exploring relationships between variables
* Creating data visualizations with Matplotlib
* Working with Scikit-learn datasets
